# aGo Files

Virtual folder organization for the WordPress media library using a custom taxonomy. Lightweight alternative to HappyFiles/FileBird. **Free, no Pro tier.**

[English](#english) · [Español](#espanol)

---

## English

aGo Files lets you organize attachments in the WordPress media library into virtual folders backed by a custom taxonomy. Folders are scoped per user role, can be reordered, nested, and assigned in bulk.

### Features

- Folder tree in the media library sidebar.
- Drag-and-drop assignment, bulk move.
- Nested folders.
- No external services.
- English, Spanish (es_ES) and Brazilian Portuguese (pt_BR) bundled.
